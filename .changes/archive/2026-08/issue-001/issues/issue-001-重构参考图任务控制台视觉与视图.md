# 重构参考图任务控制台视觉与视图

## 背景

现有 Specboard 已具备跨项目扫描、任务详情、方案与决策查看能力，但整体视觉仍偏“经营台账”，与用户提供的 Dashi Taskboard 参考图在信息密度、导航层级和任务浏览方式上差异较大。用户希望保留真实的 `.changes` / OpenSpec / Git 数据来源，同时获得更直观的仪表盘、看板和列表体验。

## 目标

将展示层重构为浅色、紧凑的任务控制台：项目下拉在顶栏切换；主视图提供仪表盘、议题看板、列表视图和项目记忆；任务仍可展开查看原有的执行、阻塞、归档和后续建议。

## 非目标

- 不建立任务数据库或改写扫描逻辑。
- 不伪造负责人、完成日期、对话、甘特时间线或 AI 结论。
- 不改动 Codex 左栏 iframe 的预取与注入机制。

## 要构建什么

用户打开本地看板后，可以从统一顶栏切换项目，在仪表盘中判断进度与关注点，在看板中按真实状态浏览任务，在列表中按状态折叠查看创建人和日期；方案、架构和决策以“项目记忆”保留可检索入口。

## 验收标准

- [x] 顶栏项目下拉、刷新与项目故事入口在桌面和窄屏可用。
- [x] 仪表盘只基于扫描数据展示完成度、状态分布、关注项与贡献来源。
- [x] 议题看板按真实 issue 状态分组，点击任务继续打开既有详情。
- [x] 列表视图按真实状态折叠展示，保留项目、创建人、创建日期、风险与进度。
- [x] 方案、计划、架构和决策能力仍可从“项目记忆”进入。
- [x] 所有原有 Node 测试通过，并以本地浏览器检查三个主视图与详情弹窗。

## 被阻塞

无，可以立即开始。

## 影响范围

`public/index.html`、`public/app.js`、`public/style.css`，以及相关 Loctek 工作/测试记录。

## 预计改动区域

- `public/index.html`
- `public/app.js`
- `public/style.css`

## 必须保留的行为

- Markdown、OpenSpec 和 Git 仍是唯一事实源。
- 项目组合扫描、项目下拉、筛选、搜索、详情弹窗、项目登记和项目故事链接继续工作。
- Codex 侧车的 localhost 预取/注入流程不得改变。

## 测试计划

- 运行 `node --check public/app.js` 和 `npm test`。
- 在 `http://127.0.0.1:47932/` 检查组合与单项目的仪表盘、看板、列表、项目记忆和任务详情。

## 回滚考虑

回滚 `public/` 的展示层文件即可；不会影响项目源记录、注册表或扫描数据。
